StartON Launchpad — Web3 платформа для запуска токенов

DFD (Data Flow Diagrams)

Диаграммы потоков данных (DFD) описывают движение информации между сервисами системы StartON Launchpad.

Нотация DFD

ЭлементОписание
Внешняя сущностьИсточник или получатель данных вне системы
ПроцессСервис или операция преобразования данных
Хранилище данныхБаза данных, смарт-контракт, файловое хранилище
Поток данныхДанные с указанием последовательности

Потоки данных:

№ПотокОписание
1Запрос лаунчейИнвестор → TMA
2Запрос данных лаунчейTMA → Oracle Service
3SQL-запросOracle → База данных
4Массив лаунчейБаза данных → Oracle
5Список лаунчейOracle → TMA
6Список лаунчей (UI)TMA → Инвестор
7Данные инвестицииИнвестор → TMA
8Запрос авторизацииTMA → TON Connect
9Запрос подключенияTON Connect → Wallet
10Адрес кошелькаWallet → TMA
11Параметры транзакцииTMA → Формирование транзакции
12Транзакция на подписьФормирование → Wallet
13Подписанная транзакцияWallet → Регистрация
14Данные транзакцииРегистрация → TON Blockchain
15Обновление балансаРегистрация → UserVault
16Подтверждение участияTON Blockchain → Инвестор

  • Время после окончания creator round
  • Токен не задеплоен (статус: Failed)
