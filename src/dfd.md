# DFD (Data Flow Diagrams)

Диаграммы потоков данных (DFD) описывают движение информации между сервисами системы StartON Launchpad.

---

## Нотация DFD

| Элемент                                       | Описание                                           |
| --------------------------------------------- | -------------------------------------------------- |
| **Внешняя сущность** (прямоугольник)          | Источник или получатель данных вне системы         |
| **Процесс** (эллипс)                          | Сервис или операция преобразования данных          |
| **Хранилище данных** (открытый прямоугольник) | База данных, смарт-контракт, файловое хранилище    |
| **Поток данных** (стрелка с номером)          | Данные с указанием последовательности (1, 2, 3...) |

**Важно:** Номера на стрелках показывают **последовательность** потоков данных.

## 1. Участие в лаунче токена через Telegram Mini App с инвестированием TON

**Потоки данных:**

| №   | Поток                  | Описание                      |
| --- | ---------------------- | ----------------------------- |
| 1   | Запрос лаунчей         | Инвестор → TMA                |
| 2   | Запрос данных лаунчей  | TMA → Oracle Service          |
| 3   | SQL-запрос             | Oracle → База данных          |
| 4   | Массив лаунчей         | База данных → Oracle          |
| 5   | Список лаунчей         | Oracle → TMA                  |
| 6   | Список лаунчей (UI)    | TMA → Инвестор                |
| 7   | Данные инвестиции      | Инвестор → TMA                |
| 8   | Запрос авторизации     | TMA → TON Connect             |
| 9   | Запрос подключения     | TON Connect → Wallet          |
| 10  | Адрес кошелька         | Wallet → TMA                  |
| 11  | Параметры транзакции   | TMA → Формирование транзакции |
| 12  | Транзакция на подпись  | Формирование → Wallet         |
| 13  | Подписанная транзакция | Wallet → Регистрация          |
| 14  | Данные транзакции      | Регистрация → TON Blockchain  |
| 15  | Обновление баланса     | Регистрация → UserVault       |
| 16  | Подтверждение участия  | TON Blockchain → Инвестор     |

## 4. Возврат средств (Refund) при неуспешном завершении лаунча

**Потоки данных:**

| №   | Поток                  | Описание                     |
| --- | ---------------------- | ---------------------------- |
| 1   | Запрос статуса лаунча  | Инвестор → TMA               |
| 2   | Запрос авторизации     | TMA → TON Connect            |
| 3   | Запрос подключения     | TON Connect → Wallet         |
| 4   | Адрес кошелька         | Wallet → TMA                 |
| 5   | Запрос данных лаунча   | TMA → Oracle Service         |
| 6   | Запрос к базе данных   | Oracle → База данных         |
| 7   | Данные лаунча (статус) | База данных → Oracle         |
| 8   | Статус и баланс        | Oracle → TMA                 |
| 9   | Доступен возврат       | TMA → Инвестор               |
| 10  | Запрос на возврат      | Инвестор → TMA               |
| 11  | Параметры возврата     | TMA → Формирование возврата  |
| 12  | Проверка условий       | Формирование → TokenLaunch   |
| 13  | Транзакция на подпись  | Формирование → Wallet        |
| 14  | Подписанная транзакция | Wallet → Выполнение возврата |
| 15  | Списание баланса       | Выполнение → UserVault       |
| 16  | Перевод TON            | UserVault → TON Blockchain   |
| 17  | Возвращённые TON       | TON Blockchain → Инвестор    |

**Условия для Refund:**

- Время после окончания creator round
- Токен не задеплоен (статус: Failed)
