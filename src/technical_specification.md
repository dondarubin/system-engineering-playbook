# Техническое задание (стандарт IEEE 29148-2011)

**StartON Launchpad — Разработка программного обеспечения для привлечения инвестиций с использованием современных решений**

---

## **1. Введение**

### **1.1 Цель документа**

Настоящий документ определяет требования к программному обеспечению (ПО) для платформы **StartON Launchpad** — децентрализованной Web3-платформы для запуска и первичного размещения токенов на блокчейне TON (The Open Network). Система состоит из следующих компонентов:

- **Набор смарт-контрактов** на блокчейне TON (Core, TokenLaunch, UserVault, Jetton);
- **Oracle Service** — сервис мониторинга блокчейна и автоматизации листинга;
- **Manager Service** — сервис управления лаунчами, задачами и пользователями;
- **Dispenser Service** — сервис управления наградами;
- **Telegram Mini App** — веб-приложение для взаимодействия пользователей;
- **AI-Chatbot** — интеллектуальный ассистент на базе LLM для поддержки пользователей.

Цель системы — предоставить создателям токенов инструмент для справедливого и прозрачного запуска проектов, а инвесторам — безопасную среду для участия в ранних стадиях криптопроектов.

### **1.2 Область применения**

Платформа предназначена для использования создателями токенов (стартапы, сообщества, проекты) и инвесторами, желающими участвовать в ранних стадиях лаунчей. Может применяться для запуска утилитарных токенов, мем-коинов и социальных токенов на блокчейне TON.

### **1.3 Предполагаемая аудитория документа**

Настоящий документ предназначен для:

- Разработчиков смарт-контрактов и backend-сервисов;
- Frontend-разработчиков Telegram Mini App;
- Тестировщиков и QA-инженеров;
- Технических руководителей проекта;
- Заказчиков и стейкхолдеров проекта.

### **1.4 Масштаб проекта**

Проект StartON Launchpad включает:

- Разработку 5 смарт-контрактов на языке FunC для блокчейна TON;
- Разработку 3 backend-сервисов (Oracle, Manager, Dispenser) на TypeScript;
- Разработку Telegram Mini App на React;
- Интеграцию AI-Chatbot на базе LLM;
- Интеграцию с двумя DEX (STON.fi, DeDust) для автоматического листинга токенов.

Проект не включает:

- Разработку собственного блокчейна;
- Разработку собственной DEX;
- Разработку мобильных приложений (используется Telegram Mini App).

## **2. Общее описание**

### **2.1 Перспектива продукта**

Система состоит из следующих основных компонентов:

**1. Смарт-контракты (OnChain):**

- **Core Contract (V1/V2)** — главный контракт-фабрика, хранит шаблоны и создаёт TokenLaunch контракты;
- **TokenLaunch Contract (V1/V2)** — контракт управления продажей токена с тремя раундами;
- **UserVault Contract (V1/V2)** — персональный контракт инвестора, хранит балансы по раундам;
- **JettonMaster / JettonWallet** — стандартные контракты токена Jetton;
- **HighloadWalletV3** — кошелёк для массовых операций (листинг, распределение).

**2. Oracle Service:**

- Сканирование Core контрактов для обнаружения новых лаунчей;
- Парсинг данных лаунчей из блокчейна;
- Интеграция с DEX (STON.fi, DeDust) для автоматического листинга;
- API для получения данных о лаунчах;
- Отправка уведомлений в Telegram.

**3. Manager Service:**

- Telegram Bot для управления лаунчами;
- API для создания лаунчей и управления пользователями;
- Управление задачами (Tasks) и наградами;
- Whitelist management;
- Загрузка метаданных в IPFS.

**4. Dispenser Service:**

- Управление пулами наград (Reward Pools);
- Обработка запросов на получение наград;
- Сканирование и распределение Jetton наград.

**5. Frontend (Telegram Mini App):**

- Интерфейс для просмотра и участия в лаунчах;
- Подключение кошелька через TON Connect;
- Управление портфелем инвестиций.

**6. AI-Chatbot на базе LLM, обеспечивающий:**

- Ответы на вопросы пользователей о работе платформы;
- Объяснение механик лаунчей;
- Помощь в создании токена.

### **2.2 Функции пользователя**

| Роль             | Функции                                                                                                                 |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Создатель токена | Загружает метаданные, запускает токен, управляет задачами, отслеживает прогресс сбора                                   |
| Инвестор         | Просматривает проекты, покупает whitelist, инвестирует в раундах, получает токены (claim), запрашивает возврат (refund) |
| Администратор    | Управляет системой через Telegram Bot: создаёт задачи, настраивает награды, модерирует лаунчи                           |

Основными функциями системы являются:

1. Создание токена через Core-контракт с загрузкой метаданных в IPFS
2. Участие в лаунче токена через Telegram Mini App с инвестированием TON
3. Получение наград из Reward Pools через Dispenser Service
4. Возврат средств (Refund) при неуспешном завершении лаунча

### **2.3 Ограничения**

- Платформа работает исключительно на блокчейне TON.
- Все транзакции требуют оплаты комиссии сети.
- Для использования платформы требуется кошелёк TON.
- AI-Chatbot работает на русском и английском языках.

### **2.4 Предположения и зависимости**

- Блокчейн TON функционирует стабильно и доступен.
- Пользователи имеют базовое понимание криптовалют и кошельков.
- DEX STON.fi и DeDust доступны для создания пулов ликвидности.
- Telegram API доступен для работы Mini App и Bot.
- Внешний LLM-провайдер (OpenAI / Anthropic) доступен для AI-Chatbot.

## **4. Нефункциональные требования**

### **4.1 Производительность**

- Время ответа API: ≤ 500 мс для 95% запросов;
- Время обнаружения нового лаунча Oracle: ≤ 60 секунд;
- Время ответа AI-Chatbot: ≤ 5 секунд;
- Поддержка сканирования нескольких Core контрактов параллельно;
- Интервал сканирования блокчейна: 30-60 секунд.

### **4.2 Надёжность**

- Oracle должен автоматически восстанавливаться после сбоев и продолжать сканирование с сохранённой позиции.
- Все критические операции должны логироваться.
- AI-Chatbot должен корректно обрабатывать ошибки LLM-провайдера.

### **4.3 Безопасность**

- Смарт-контракты должны пройти аудит безопасности.
- API должен использовать HTTPS.
- Авторизация через TON Connect с криптографической подписью.
- AI-Chatbot не должен раскрывать конфиденциальную информацию о системе.

### **4.4 Удобство использования**

- Интерфейс должен быть интуитивно понятным.
- Поддержка русского и английского языков.
- AI-Chatbot должен давать понятные и структурированные ответы.

### **4.5 Совместимость**

- Поддержка кошельков: TON Keeper, Tonhub, MyTonWallet.
- Telegram: версия с поддержкой Mini App.
- Интеграция с DEX: STON.fi, DeDust.

## **5. Внешние интерфейсы**

### **5.1 Интерфейсы пользователя (UI)**

- Telegram Mini App: список лаунчей, страница проекта, портфель, система задач, встроенный AI-чат.
- Telegram Bot: интерфейс администратора для управления системой.

### **5.2 Программные интерфейсы**

- TON Blockchain: взаимодействие со смарт-контрактами через TonLib.
- TON Connect: протокол авторизации и подключения кошелька.
- STON.fi / DeDust: API для создания пулов ликвидности.
- IPFS: хранение метаданных токенов.
- OpenAI API / Anthropic API: LLM для AI-Chatbot.
- Telegram Bot API: уведомления и управление.

## **6. Другие требования**

- Документация по развёртыванию каждого сервиса.
- API-документация в формате Swagger/OpenAPI.
