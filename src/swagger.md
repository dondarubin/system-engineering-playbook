# Swagger API

Документация публичного API платформы StartON Launchpad в формате OpenAPI 3.0.

## Сервисы

API платформы разделён на три сервиса:

| Сервис                | Описание                                                  |
| --------------------- | --------------------------------------------------------- |
| **Oracle Service**    | Получение данных о лаунчах, поиск и фильтрация            |
| **Manager Service**   | Управление лаунчами, пользователями, задачами и whitelist |
| **Dispenser Service** | Управление наградами и их распределением                  |
