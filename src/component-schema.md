# Компонентная схема сервисов

Схема иллюстрирует архитектуру платформы StartON Launchpad — децентрализованной Web3-платформы для запуска токенов на блокчейне TON.

## Ключевые компоненты

### Пользователи

- **Создатель токена** — запускает новые токенсейлы через платформу
- **Инвестор** — участвует в токенсейлах и получает награды
- **Администратор** — управляет платформой через Telegram Bot

### Frontend

- **Telegram Mini App** — основной пользовательский интерфейс для участия в токенсейлах
- **AI-Chatbot** — интеллектуальный помощник на базе LLM для ответов на вопросы пользователей
- **TON Connect** — протокол авторизации через TON-кошелёк
- **Telegram Bot** — интерфейс для администрирования платформы

### Backend Services

- **Oracle Service** — сканирует блокчейн TON, отслеживает транзакции токенсейлов, интегрируется с DEX
- **Manager Service** — управляет лаунчами, пользователями, задачами, загружает метаданные в IPFS
- **Dispenser Service** — управляет пулами наград и распределяет Jetton-награды через HighloadWallet

### Хранилище данных

- **PostgreSQL** — основная база данных для хранения состояния системы
- **IPFS** — децентрализованное хранилище метаданных токенов

### TON Blockchain (Смарт-контракты)

- **Core Contract** — фабрика для создания новых токенсейлов
- **TokenLaunch Contract** — управляет жизненным циклом токенсейла
- **UserVault Contract** — хранит инвестиции пользователей
- **Jetton Contracts** — стандартные контракты токенов (JettonMaster/JettonWallet)
- **HighloadWalletV3** — кошелёк для массовой рассылки транзакций

### Внешние системы

- **DEX (STON.fi / DeDust)** — децентрализованные биржи для листинга токенов
- **LLM API (OpenAI/Anthropic)** — API для AI-Chatbot
- **Telegram API** — API для работы с Telegram Bot
